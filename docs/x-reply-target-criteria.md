# X Reply Target Criteria

The X reply-target workflow uses the X recent-search API and a deterministic
query set. A strong target should be:

- within the last 4 hours
- relevant to property-management operations
- specific enough to support a useful operational reply
- low-risk to engage publicly

The current score adds weight for:

- freshness
- property-management or multifamily language
- clear operational pain
- operator-like accounts instead of generic brand/news noise

The current score subtracts weight for:

- webinar or download promos
- job posts
- obvious sales/demo CTAs
- extremely short or low-context posts
